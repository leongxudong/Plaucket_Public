# Contributing to Plaucket

Thanks for helping make private meeting capture more accessible.

1. Create a branch from `main`.
2. Run `npm install`.
3. Make a focused change with tests where practical.
4. Run `npm run check && npm run build`.
5. Open a pull request describing the privacy or security impact of the change.

Never commit recordings, transcripts, `.env`, `.dev.vars`, cloud credentials, access tokens, or API keys. Security-sensitive changes should include a short threat analysis in the pull request.
